# Apple-Minimalist UX Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Transform the VDOT/CannaAfrica UI into a flat, spacious, Apple-enterprise-style interface — white navbar, no zebra striping, lighter borders, clean typography, flat modals and dropdowns.

**Architecture:** All changes are confined to a single LESS file (`resources/assets/less/overrides.less`). Each task patches one section. After all tasks, run `npm run dev` once to rebuild the CSS build artifact, then commit everything.

**Tech Stack:** LESS CSS, Laravel Mix (`npm run dev`), Bootstrap 3 + AdminLTE overrides

**Spec:** `docs/superpowers/specs/2026-04-20-apple-minimalist-ux-design.md`
